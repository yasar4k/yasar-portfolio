# Yasar — Video Editor Portfolio

A responsive, single-page portfolio built with plain HTML, CSS, and JavaScript. Existing video thumbnails and thumbnail-design images were reused from the current Framer portfolio; the original YouTube videos open in an on-page player.

## Preview

Open `index.html` in a browser, or run a local server from this folder:

```sh
python3 -m http.server 8000
```

Then visit <http://localhost:8000>.

## Easy updates

- Change copy, links, sections, or sample video IDs in `index.html`.
- Replace the local images in `assets/` to update the portfolio visuals.
- Edit colors and responsive styles in `styles.css`.
- Update menu and player behavior in `script.js`.

The Calendly CTA uses the booking link already published on Yasar's current site. No unverified client quotes, metrics, or client identities are included.
